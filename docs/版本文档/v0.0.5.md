# v0.0.5

目标：在 v0.0.4 完成 React + Vite 单 UI 与可持续知识库闭环后，补齐主流旅游规划产品的协作、预订、预算、路线优化、离线与编排能力，形成可交付的产品化体验。

## 核心需求

### P1：协作与共享
目标：支持多人协作与共享，形成团队旅行的可用体验。

范围（功能性）：
- 行程分享：可生成只读/可编辑链接
- 协作编辑：多人同时编辑行程并同步地图与列表
- 权限管理：拥有者/编辑者/查看者三档

验收标准（最小可用）：
- 至少支持 1 个行程的多人协作编辑，变更在 3 秒内同步到其他端
- 生成分享链接并可设置只读/可编辑权限
- 权限控制可覆盖新增/删除/修改行程项

### P1：预订导入与行程自动整理
目标：从邮件或文件导入机酒订单并自动结构化到行程中。

范围（功能性）：
- 订单导入：邮件转发/上传文件导入机票/酒店/活动订单
- 自动归档：按日期与城市自动归类到日程
- 手动校正：导入失败可手动补全关键字段

验收标准（最小可用）：
- 支持至少 1 种导入方式（邮件或文件）成功解析机票/酒店订单
- 导入数据可自动落入正确日期并展示在行程与地图上
- 导入失败的订单可手动补全并保存

### P1：预算与费用管理
目标：支持预算设置、费用记录与分摊。

范围（功能性）：
- 预算与花费：总预算/分类预算/支出记录
- 费用分摊：多人出行分摊与结算
- 报表视图：按天/按类别统计

验收标准（最小可用）：
- 可为单个行程设置预算并记录至少 10 条支出
- 支持多人分摊与结算结果展示
- 支持按天与按类别的花费汇总

### P2：路线优化与多停靠点规划
目标：补齐跨城市/自驾场景的路线优化能力。

范围（功能性）：
- 多停靠点排序优化与里程/时间评估
- 路线偏好：最短/避开高速/公共交通
- 地图对齐：优化结果同步到行程与地图

验收标准（最小可用）：
- 对同日 5 个以上停靠点提供自动排序优化
- 输出里程与时长评估并同步到行程展示
- 路线偏好切换后能重新计算并更新地图

### P2：预订与价格联动
目标：为机票/酒店/门票提供比价与跳转预订入口。

范围（功能性）：
- 价格查询与对比
- 跳转预订或合作入口

验收标准（最小可用）：
- 至少支持 1 类目（机票/酒店/门票）价格查询与对比
- 提供可用的跳转入口并记录来源

### P2：离线可用与行前提醒
目标：支持低网环境访问与行前提醒。

范围（功能性）：
- 离线行程访问
- 行前提醒与变更通知

验收标准（最小可用）：
- 行程可离线访问并保留地图或关键列表信息
- 支持至少 2 类提醒（行前 24 小时/当天行程）

### P2：流程编排配置化
目标：让“工具调用 + 多知识库路由 + 回答生成/行程生成”变成可配置的流程。

范围（功能性）：
- 编排方式
  - 支持把当前链路拆为可配置节点：输入解析 → 选择知识库 → 检索 → 生成行程 → 校验/优化 → 输出（含地图/证据）
  - 支持为不同场景提供不同流程模板（例如：城市攻略问答 vs 结构化行程生成）
- 工具与接口
  - 现有工具（天气/地理编码/POI/检索）能够以“标准化接口”暴露给编排层调用
  - 支持把“行程生成服务”对外暴露为 API（便于编排层或未来 Web 前端调用）

可选实现路径（两条都算达标）：
- Path A：集成 Dify 作为外部编排器（TripNexus 以工具/API 形式对接）
- Path B：继续使用 LangGraph，但补齐“流程配置化”（例如：以配置文件/可视化面板选择节点组合、参数与路由规则）

验收标准（最小可用）：
- 可切换至少 2 条流程模板（问答/行程），且无需改代码即可切换
- 任一流程模板能指定使用不同知识库集合（例如：目的地 A 与目的地 B 两套数据集）

## 可落地的开发步骤
### 1. 协作与共享基础能力
- 统一行程权限模型：拥有者/编辑者/查看者
- 实现分享链接生成与权限绑定
- 建立实时协作通道（WebSocket/轮询二选一）
- 前端接入协作状态与冲突提示

### 2. 预订导入最小闭环
- 选择首个导入方式（邮件或文件），打通上传与解析链路
- 实现订单结构化抽取并落库（机票/酒店至少一种）
- 自动归档到日程，并支持手动补全与保存

### 3. 预算与费用管理 MVP
- 建立预算/支出数据模型与基础 API
- 前端实现预算设置与支出录入
- 输出按天/按类别的基础汇总视图

### 4. 路线优化与地图同步
- 接入路线计算能力并支持多停靠点排序优化
- 输出里程与时长评估并同步到行程
- 前端支持路线偏好切换并触发重新计算

### 5. 预订与价格联动试点
- 选定首个类目（机票/酒店/门票）价格查询入口
- 提供跳转与来源记录能力
- 前端展示比价结果与跳转按钮

### 6. 离线与行前提醒最小能力
- 提供离线访问缓存策略（行程与关键列表）
- 建立提醒规则（行前 24 小时/当天行程）与通知触发
- 前端提供提醒开关与状态提示

### 7. 流程编排配置化落地
- 抽象流程模板配置结构（节点/参数/路由）
- 让问答与行程两条模板可配置切换
- 暴露工具与行程生成 API 给编排层调用

### 8. 关键验收与回归
- 协作编辑与权限控制满足最小验收
- 至少 1 种订单导入可完成解析与归档
- 预算记录、路线优化、离线与提醒可用
