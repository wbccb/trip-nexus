# v0.0.2

目标：在最小化MVP的基础上，集成主流技术和交互

## 核心需求
1. frontend: 实现前端对话式更新行程
2. rag: 爬虫优化，提高数据采集稳定性
3. llm: LLM 双模式支持（线上 + 本地）
4. map: 多地图切换 + POI 样式定制:基于 CSS Sprite+SVG，实现轻量、清晰的分类渲染 + POI 层级渲染：通过四叉树实现按需渲染，避免遮挡与卡顿

> 注：在弄清楚技术原理的基础上使用已经有的成熟轮子，不要自己造轮子，可以二次开发！！！！！！！


> 下面按照开发顺序进行排列模块具体开发内容

## frontend
1. 实现前端多轮对话交互
2. 实现多轮对话
- 上下文管理与压缩
- 会话管理: 持久化 + 多设备同步

## rag
1. 调研目前主流大模型【网络搜索】的技术方案: 提高数据采集稳定性 + 数据清理，只存储有意义的数据
2. 优化数据采集存储和实时查询的逻辑交互（不是每一次采集都得存储）
3. 支持多轮对话多次采集数据并且筛掉之前已经搜索过的网络地址
> 后期集成RagFlow，将爬虫数据存储到RagFlow进行检索 + 允许用户在RagFlow中上传文档进行检索
