# v0.0.3 修复bug记录


### 修复记录 2026-02-05
- **问题现象**：启动或新建会话时，终端多次出现 all-MiniLM-L6-v2 与设备信息加载日志，界面卡顿。
- **原因分析**：Streamlit rerun 导致重复实例化 RAG 管线，IntentRecognizer 与向量嵌入各自创建 SentenceTransformer，触发重复加载。
- **解决方案**：
  - 将 SentenceTransformer 实例收敛到可复用的缓存入口，并让向量嵌入复用同一模型实例。
  - **涉及文件**：src/frontend/ui_manager.py，src/rag/module/intent_recognition.py，src/rag/store/vector_store.py

### 修复记录 2026-02-07
- **问题现象**：流式输出结束后，HTML 中直接包含 `\n\n`，Streamlit Markdown 渲染误判为分段，导致界面错乱。
- **原因分析**：非流式重渲染路径未对换行做 HTML 化处理，`\n\n` 被当作段落分隔符解析。
- **解决方案**：
  - 流式与非流式渲染统一将换行替换为 `<br/>`，避免 Markdown 分段误判。
  - **涉及文件**：src/frontend/chat_stream_renderer.py
