# 地图显示调研与集成方案

## 1. 核心需求分析

根据 v0.0.2 版本规划，地图模块的核心需求如下：
1. **多地图切换**：支持不同底图源（如高德、Mapbox、OSM）切换。
2. **POI 样式定制**：基于 CSS Sprite + SVG 实现轻量、清晰的分类渲染。
3. **POI 层级渲染**：使用四叉树（或聚类）实现按需渲染，避免遮挡与卡顿。
4. **免费/低成本集成**：调研免费或有免费额度的成熟方案。

## 2. 地图集成方案调研

鉴于项目当前使用 `Streamlit` + `folium` (Leaflet wrapper)，以下方案基于此技术栈进行评估。

### 2.1 底图服务商 (Tile Providers)

| 服务商 | 适用场景 | 优点 | 缺点 | 免费额度 | 集成方式 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **OpenStreetMap (OSM)** | 全球通用 | 完全免费，开源，无需 Key | 样式单一，加载速度一般，中文支持一般 | 无限制 | Folium 默认 |
| **高德地图 (Amap)** | **国内首选** | 数据最准，POI 丰富，加载快 | 海外数据弱，需自定义 Tile URL | 个人开发者免费 | 通过 XYZ URL 接入 |
| **Mapbox** | 全球 + 定制 | 样式极美，支持高度定制，矢量瓦片 | 需绑定信用卡，配置稍繁琐 | 50,000 次加载/月 | 需 API Key |
| **CartoDB** | 全球通用 | 简洁美观，适合做底图 | 免费版样式有限 | 开源免费 | Folium 内置支持 |

**结论与建议**：
- **MVP 阶段**：采用 **混合策略**。
    - 默认底图：使用 **高德地图 (Amap)** 卫星/街道图（通过 URL 模板接入），保障国内体验。
    - 备选底图：保留 **CartoDB Positron**（简洁灰白风，适合突出行程路线）和 **OSM**。
    - 进阶：后续可接入 Mapbox 提升海外体验（需申请 Key）。

### 2.2 技术实现方案

#### A. 多地图切换 (Multi-map Switching)
利用 `folium.LayerControl` 和 `folium.TileLayer` 实现。可以同时加载多个图层，用户在右上角控件自由切换。

```python
# 示例代码逻辑
m = folium.Map(...)
# 添加高德街道图
folium.TileLayer(
    tiles='http://webrd02.is.autonavi.com/appmaptile?lang=zh_cn&size=1&scale=1&style=7&x={x}&y={y}&z={z}',
    attr='高德地图',
    name='高德街道'
).add_to(m)
# 添加高德卫星图
folium.TileLayer(
    tiles='http://webst02.is.autonavi.com/appmaptile?style=6&x={x}&y={y}&z={z}',
    attr='高德地图',
    name='高德卫星'
).add_to(m)
folium.LayerControl().add_to(m)
```

#### B. POI 样式定制 (CSS Sprite + SVG)
利用 `folium.DivIcon` 替代默认的 `Marker` 图标。`DivIcon` 允许直接传入 HTML/CSS。

- **实现原理**：
    - 定义 CSS Class，使用 `background-image` 引用 SVG Sprite 雪碧图。
    - 通过 `background-position` 定位不同类型的图标（餐饮、景点、住宿）。
    - 结合 HTML 结构实现轻量级渲染。

```python
# 示例代码逻辑
folium.Marker(
    location=[lat, lon],
    icon=folium.DivIcon(
        html='<div class="poi-marker type-attraction"></div>',
        class_name="custom-marker-container"
    )
)
```

#### C. POI 层级渲染 (Quadtree/Clustering)
利用 `folium.plugins.MarkerCluster` 实现。
- **原理**：底层 Leaflet 使用基于距离的聚类算法（类似 Quadtree 思想），当缩放层级较低（视野大）时，将临近点聚合为一个数字图标；放大后展开。
- **优势**：解决大量 POI 导致的地图卡顿和遮挡问题。

```python
from folium.plugins import MarkerCluster
marker_cluster = MarkerCluster().add_to(m)
folium.Marker(...).add_to(marker_cluster)
```
